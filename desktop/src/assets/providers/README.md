# Provider logos

These assets identify the configured CLI provider and ship locally for offline use.

- `claude.svg`: Claude symbol, from [Lobe Icons](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/claude-color.svg).
- `codex.svg`: Codex symbol, from [Lobe Icons](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/codex.svg). Rendered as a CSS mask so the monochrome mark follows the theme.
- `gemini.svg`: Gemini symbol, from [Google's Gemini asset CDN](https://www.gstatic.com/lamda/images/gemini_sparkle_aurora_33f86dc0c0257da337c63.svg), referenced by gemini.google.com.

Retrieved 2026-10-10. Lobe Icons' MIT license is included in `LICENSE.lobe-icons`. Brand names and marks belong to their respective owners. Keep the original artwork and brand colours; do not substitute generated approximations. Adjacent provider labels supply accessible names.
